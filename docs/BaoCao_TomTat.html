1. Tổng quan dự án

HASAKI là website thương mại điện tử bán mỹ phẩm được xây dựng lại từ đầu bám sát theo báo cáo đồ án tốt nghiệp của sinh viên Lê Thị Kim Phụng. Source code triển khai đầy đủ 11 bảng database theo thiết kế gốc, mở rộng thêm 5 bảng phụ cho các tính năng nâng cao (chatbot, settings, reviews, menu).

Hạng mục Mô tả
Frontend HTML5 + SCSS (compiled) + Tailwind CSS 3.4 + Vanilla JavaScript
Backend PHP 8.2 thuần, mô hình 3-Layer (DAL → BLL → Controller/View)
Database MySQL 8 / MariaDB 10.5+, UTF-8mb4, 16 bảng
Web server Apache (Laragon) hoặc PHP built-in
Thư viện FE Font Awesome 6.4, Plus Jakarta Sans + Playfair Display, Chart.js 4.4
Số file PHP ~70 file (config, helpers, DAL, BLL, view, admin)
Tổng dòng code ~12.000+ dòng (PHP + SCSS + JS + SQL)

2. Kiến trúc & công nghệ

Áp dụng đúng mô hình 3-Layer được mô tả trong mục 2.6 của báo cáo đồ án: 

[ Controller / View  (public/*.php, public/admin/*.php) ]
                     ↓
[ Business Layer     (src/Business/*BLL.php)            ]
                     ↓
[ DataAccess Layer   (src/DataAccess/*DAL.php)          ]
                     ↓
[ MySQL              (PDO Prepared Statements)          ]
  • DataAccess (DAL): chỉ thực hiện truy vấn SQL qua PDO. Mỗi entity có 1 file DAL riêng (ProductDAL, InvoiceDAL, ChatbotDAL...).
  • Business (BLL): validate input, xử lý nghiệp vụ (login, checkout giảm tồn, status update, fuzzy intent matching cho chatbot...), gọi các DAL liên quan.
  • Controller / View: file PHP trong public/ nhận request, gọi BLL, render view với HTML + Tailwind.

Bảo mật

  • Mật khẩu lưu bằng bcrypt qua password_hash / password_verify.
  • Tất cả query qua PDO Prepared Statement → chống SQL injection.
  • Tất cả output qua e() = htmlspecialchars → chống XSS.
  • require_login(), require_admin() bảo vệ các route nội bộ.
  • CSRF token có sẵn (csrf_token(), verify_csrf()) cho mọi form quan trọng.
  • UTF-8mb4 trên cả DB lẫn PDO init command (SET NAMES utf8mb4) — fix hoàn toàn lỗi mojibake.

8. AI Chatbot

Chatbot rule-based được tùy chỉnh hoàn toàn qua admin panel.

  • Cơ chế: Khử dấu tiếng Việt (à/á/ả → a, đ → d...) → match keyword chứa từ khóa của intent → trả về câu trả lời.
  • 21 intents seed: Chào hỏi, Đặt hàng, Giao hàng, Đổi trả, Thanh toán, Tư vấn da khô/dầu/nhạy cảm/mụn, Son môi, Kem chống nắng, Nước hoa, Sale, Bán chạy...
  • Loại gợi ý sản phẩm: none / search (theo từ khóa) / featured (sản phẩm sale) / newest (sản phẩm mới)
  • Fallback search: Nếu không match intent nào, tự động search trong DB sản phẩm
  • Quick reply chips: Hiển thị các intent được đánh dấu LaQuickReply=1 dưới dạng nút bấm nhanh
  • Widget UI: Floating bubble góc phải, gradient header, typing indicator, product card mini, markdown nhẹ (**bold**)
  • Admin live preview: Test thử câu hỏi ngay trong trang quản trị, xem bot trả lời với products thật

13. Bug fixes đáng chú ý

13.1 Encoding mojibake (Vietnamese)

Vấn đề: mysql.exe trên Windows mặc định đọc file SQL với codepage CP437/CP850. File migrate_chatbot.sql UTF-8 khi import qua mysql CLI bị double-encoded: bytes UTF-8 được interpret qua CP437 trước khi lưu utf8mb4 → mojibake (Chào hỏi → Ch├áo hß╗Åi).
Fix: Thêm SET NAMES utf8mb4; ở đầu file SQL, run với --default-character-set=utf8mb4, và thêm PDO::MYSQL_ATTR_INIT_COMMAND => "SET NAMES utf8mb4" cho mọi connection PHP.

13.2 Button hover translate gây ghost edge

Vấn đề: Các button gradient brand dùng hover:-translate-y-0.5 + transition-all tạo ghost edge / shadow trail trong screenshot, đặc biệt khi focus/active.
Fix: Thay transition-all bằng transition-shadow, bỏ translate hover, thêm focus-visible:ring-2 ring-brand-300 ring-offset-2. Áp dụng cho 6 nút brand-gradient toàn site.

13.3 Password toggle chỉ hiện chứ không tắt được

Vấn đề: JS dùng selector input[type="password"] để tìm input cần toggle. Sau click lần 1, input đã đổi thành type="text" → click lần 2 selector không tìm thấy → toggle không hoạt động.
Fix: Đổi sang selector chung wrap.querySelector('input') (không filter theo type) - mỗi .pw-field chỉ chứa 1 input nên không cần filter.

13.4 Sticky tab nav che heading khi switch tab

Vấn đề: Tab nav trang chi tiết sản phẩm có sticky top-[68px]. Khi user scroll xuống rồi click tab khác, scroll position giữ nguyên → heading của panel mới bị tab nav che đầu.
Fix: Bỏ sticky + thêm smart scroll: khi click tab, JS scroll page về vị trí tab nav ngay dưới site header nếu user đang scroll thấp hơn.

13.5 Toàn bộ data từ ASCII sang tiếng Việt có dấu

Migration v2: Update 6 DanhMuc + 16 SanPham + 5 NhanVien + 7 KhachHang sang tiếng Việt có dấu chuẩn UTF-8. Thêm 8 cột chi tiết vào SanPham (ThuongHieu, XuatXu, DungTich, LoaiDa, ThanhPhan, HuongDanSuDung, BaoQuan, HanSuDung). Tạo bảng DanhGia + seed 27 reviews.

13.6 Nav header bị wrap 2 dòng

Fix: Thêm whitespace-nowrap cho tất cả nav items, đổi "Về chúng tôi" → "Giới thiệu", giảm gap. Mọi item giờ chỉ 1 dòng kể cả màn hình hẹp.

13.7 Anchor hover override Tailwind text-white

Vấn đề: Rule global a:hover { color: $brand-primary } có specificity (0,1,1) cao hơn Tailwind .text-white (0,1,0) → text trắng trên gradient pink biến thành pink trùng nền → chìm khi hover.
Fix: Wrap bằng :where() để giảm specificity về 0: :where(a:hover) { color: $brand-primary }. Anchor "trần" vẫn hover sang brand, anchor có text-X explicit không bị ghi đè.

13.8 Password toggle vị trí lỗi (icon overlap dots)

Vấn đề: Cách dùng position: absolute cho button toggle gây overlap với password dots trên một số trình duyệt/zoom level.
Fix: Refactor thành SCSS component .pw-field dùng flex layout: wrapper là "ô input giả" có border, input thật và button là flex siblings. Không phụ thuộc absolute positioning, layout 100% deterministic.

15. Hướng dẫn cài đặt

15.1 Yêu cầu

  • Laragon (khuyến nghị) hoặc XAMPP/WAMP
  • PHP 8.0+ (đã test với PHP 8.2.30)
  • MySQL 8 hoặc MariaDB 10.5+
  • Node.js 18+ (chỉ cần khi muốn build lại CSS)

15.2 Các bước

1. Đặt source code vào C:\laragon\www\hasaki\ (hoặc I:\laragon\www\hasaki\)

2. Tạo database:
   mysql -uroot --default-character-set=utf8mb4 < database/schema.sql
   mysql -uroot --default-character-set=utf8mb4 < database/migrate_chatbot.sql
   mysql -uroot --default-character-set=utf8mb4 < database/migrate_v2.sql
   mysql -uroot --default-character-set=utf8mb4 < database/migrate_v3.sql
   mysql -uroot --default-character-set=utf8mb4 < database/seed_orders.sql

3. (Tùy chọn) Build lại CSS:
   npm install
   npm run build

4. Truy cập:
   http://localhost/hasaki          (trang khách)
   http://localhost/hasaki/admin    (admin login)
